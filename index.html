Dev Panel

Painel web de hospedagem para VPS Ubuntu

O Dev Panel é um painel web para administrar uma VPS Ubuntu pelo navegador. Ele é um único programa, instalado e executado pelo próprio usuário no servidor dele, com a interface embutida e os dados guardados num banco local nesse servidor. É um projeto pessoal, sem fins comerciais, mantido por Elimarcos Morais.

O que ele faz

  • Mostra o uso de CPU, memória, disco e rede do servidor.
  • Instala, atualiza e configura aplicativos como Nginx, PHP, MySQL, PostgreSQL, Redis e Node.js.
  • Cria bancos de dados, gerencia arquivos, abre um terminal e controla o firewall.
  • Publica sites, inclusive a partir de um repositório do GitHub.
  • Vincula uma conta do Google Drive para guardar os backups dos projetos e enviar a ela os arquivos e as pastas do servidor que o usuário escolher.
  • Vincula uma conta Microsoft do OneDrive, com acesso restrito à pasta do app (Apps/Dev Panel).

Conexão com o Google Drive

Em Configurações → Conectores, o usuário pode vincular uma conta do Google Drive ao painel instalado no servidor dele. A autorização é feita na página do próprio Google, e o Dev Panel pede só o escopo https://www.googleapis.com/auth/drive.file: ele alcança apenas os arquivos e as pastas que o próprio Dev Panel cria no Drive (os backups e o que o usuário envia pelo gerenciador de arquivos), nunca o resto do Drive.

Os dados da conta Google ficam no servidor de quem instalou o painel e não são enviados ao desenvolvedor nem a terceiros. Os detalhes estão na Política de Privacidade.

Conexão com o OneDrive

Em Configurações → Conectores, o usuário também pode vincular uma conta Microsoft (pessoal, de trabalho ou de escola) ao painel. A autorização é feita na página da própria Microsoft, e o Dev Panel pede só a permissão Files.ReadWrite.AppFolder do OneDrive, que alcança apenas a pasta Apps/Dev Panel criada pela Microsoft para o app, nunca o resto do OneDrive, além de User.Read, para mostrar o e-mail da conta conectada, e offline_access, para manter o vínculo.

Os dados da conta Microsoft também ficam só no servidor de quem instalou o painel e não são enviados ao desenvolvedor nem a terceiros. Os detalhes estão na Política de Privacidade.

English

Dev Panel is a web hosting control panel for Ubuntu VPS servers. It is a single program that each user installs and runs on their own server, with its data kept in a local database on that server. It is a personal, non-commercial project maintained by Elimarcos Morais.

Users can link a Google Drive account to store project backups and to send it the server files and folders they choose. Dev Panel requests only the https://www.googleapis.com/auth/drive.file scope, so it reaches only the files and folders it creates itself. Google account data stays on the user's server and is never sent to the developer or to third parties.

Users can also link a Microsoft account (personal, work or school) for OneDrive. Dev Panel requests only the Files.ReadWrite.AppFolder OneDrive permission, which reaches only the app folder Microsoft creates for it (Apps/Dev Panel), never the rest of OneDrive, plus User.Read, to show the connected account's email, and offline_access, to keep the link. Microsoft account data also stays on the user's server and is never sent to the developer or to third parties. See the Privacy Policy.
